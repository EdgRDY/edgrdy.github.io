# Psichologės svetainė

Statinė svetainė (HTML + CSS + vanilla JS), hostinama per GitHub Pages.

Šiuo metu: dizaino peržiūros režimas. Puslapyje apačioje dešinėje yra perjungiklis A / B / C,
leidžiantis palyginti tris dizaino variantus. Išsirinkus variantą, likę du bus pašalinti,
o svetainė užbaigta (SEO, privatumo politika, formos endpoint, tikri kontaktai).
